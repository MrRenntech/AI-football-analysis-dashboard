# How to Run the Project (Step-by-Step)

This guide assumes you are on Windows, Mac, or Linux and have a terminal open.

---

## 1. Prerequisites / System Requirements

### A. Install Python
- Ensure you have Python **3.8** or newer installed.
- Check by running:
  ```bash
  python --version
  ```

### B. Install Git (Optional but recommended)
- To clone the repo. If you downloaded the zip, skip this.

---

## 2. Installation Setup

### Step 1: Open Terminal
Navigate to the project root directory (where this file is located):
```bash
cd "path/to/AI-football-analysis-dashboard-main"
```

### Step 2: Install Dependencies
This puts all required AI libraries on your machine.
```bash
pip install -r football_cv/requirements.txt
```
*Note: This may take a few minutes as it downloads PyTorch and YOLOv8 weights.*

---

## 3. Preparing Input Data

1.  Find a football video (MP4 format preferred).
2.  Rename it to `input.mp4`.
3.  Place it exactly in this folder:
    `football_cv/data/input.mp4`

*If the folder `football_cv/data` does not exist, create it.*

---

## 4. Running the Analysis Pipeline

Run the main python script:
```bash
python football_cv/src/pipeline.py
```

### What to expect during the run:
1.  **Initialization**: You will see messages about loading the YOLO model (downloading the model weights `yolov8x.pt` if it's the first run).
2.  **Video Info**: It will print the resolution and FPS of your video.
3.  **Processing**: You will see a progress log like:
    ```
    Processed frame 0...
    Processed frame 50...
    Processed frame 100...
    ```
    *Speed depends on your GPU/CPU. It is normal for this to be slower than real-time.*

---

## 5. Viewing Results

1.  Wait for the script to print `Done!`.
2.  Navigate to the output folder:
    `football_cv/output/`
3.  Open `annotated_output.mp4` with any video player (VLC, Media Player).

### What you should see:
- **Bounding Boxes**: Around players (Green/detected colors) and the ball (Yellow).
- **ID Numbers**: Every player has a unique `#ID` above their head.
- **Possession Tag**: The player with the ball will have a `POSSESSION` tag or marker.

---

## Troubleshooting

- **"Module not found" error**:
  Run `pip install -r football_cv/requirements.txt` again. Ensure you are in the correct directory.

- **"File not found" error**:
  Check that `football_cv/data/input.mp4` exists.

- **Slow Performance**:
  The code uses `yolov8x` (Extra Large) for maximum accuracy. For faster (but less accurate) results, you can edit `pipeline.py` and change `"yolov8x.pt"` to `"yolov8n.pt"`.
